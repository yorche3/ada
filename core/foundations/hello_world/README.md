## 📄 Archivos clave / Key Files

**ES:** Para que Alire reconozca y compile este proyecto se necesitan **tres archivos mínimos**, creados a mano:

**EN:** For Alire to recognize and compile this project, **three minimal files** are needed, created by hand:

### `alire.toml`

**ES:** Manifiesto del proyecto para Alire. Declara el nombre, versión, autor/es y —lo más importante— el/los ejecutables que genera. Sin este archivo, Alire no sabe que existe el proyecto.

**EN:** Project manifest for Alire. Declares the name, version, author(s), and —most importantly— the executable(s) it generates. Without this file, Alire doesn't know the project exists.

```toml
name = "hello_world"
version = "0.1.0-dev"
authors = ["Your Name"]
licenses = "MIT OR Apache-2.0"
executables = ["hello_world"]
```

### `hello_world.gpr`

**ES:** Proyecto GPRbuild. Define cómo compilar: qué archivos fuente usar (`hello_world.adb`), dónde dejar los objetos compilados (`obj/`), dónde dejar el ejecutable (`bin/`), y switches del compilador (`-s` para recompilar si cambian las fuentes).

**EN:** GPRbuild project file. Defines how to compile: which source files to use (`hello_world.adb`), where to place compiled objects (`obj/`), where to place the executable (`bin/`), and compiler switches (`-s` to recompile if sources change).

```gpr
project Hello_World is
   for Languages use ("Ada");

   package Builder is
      for Switches ("Ada") use ("-s");  --  Recompile if source changes
   end Builder;
   for Object_Dir use "obj";
   for Create_Missing_Dirs use "True";
   for Exec_Dir use "bin";
   for Main use ("hello_world.adb");

   package Binder is
      for Switches ("Ada") use ("-Es");
   end Binder;
end Hello_World;
```

### `.gitignore`

**ES:** Evita que se versionen los directorios generados por la compilación (`bin/`, `obj/`) y por Alire (`alire/`). Todo eso se regenera con `alr exec -- gprbuild...`.

**EN:** Prevents versioning of directories generated by compilation (`bin/`, `obj/`) and by Alire (`alire/`). Everything is regenerated with `alr exec -- gprbuild...`.

```gitignore
alire/
bin/
obj/
```

## 🚀 Compilar y ejecutar / Build & Run

### Con Alire (recomendado)

```bash
# Compilar usando la toolchain de Alire
alr exec -- gprbuild -P hello_world.gpr

# Ejecutar
./bin/hello_world
```

**Salida esperada / Expected output:**

```text
Hello, World! from Ada!
```

### Con gprbuild (directo, sin Alire)

> **ES:** Si tienes GNAT y gprbuild instalados globalmente (sin Alire), puedes compilar directamente:
> **EN:** If you have GNAT and gprbuild installed globally (without Alire), you can compile directly:

```bash
gprbuild -p -P hello_world.gpr
./bin/hello_world
```

---

**ES:** La toolchain (Alire 2.1.0, gnat_native 15.2.1, gprbuild 25.0.1) se configura globalmente. Ver [`ada/Readme.md`](https://yorche3.github.io/programming_languages/ada/) para instrucciones de instalación.  
**EN:** The toolchain (Alire 2.1.0, gnat_native 15.2.1, gprbuild 25.0.1) is configured globally. See [`ada/Readme.md`](https://yorche3.github.io/programming_languages/ada/) for installation instructions.
